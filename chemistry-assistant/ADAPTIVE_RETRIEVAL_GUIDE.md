# 🔍 自适应检索功能使用指南

## 概述

自适应检索（Adaptive Retrieval）是化学助手的高级功能，它能够根据查询的复杂度动态调整检索策略，从而提供更精准、高效的答案。该功能通过智能分析用户问题的复杂程度，自动选择最适合的检索方法，既减少了不必要的计算开销，又提高了响应的准确性。

## 核心特性

### 🧠 智能复杂度分析
- **自动评估**: 使用先进的算法分析查询的复杂度
- **多维度评分**: 从语法复杂度、语义深度、计算需求等多个维度评估
- **实时分析**: 支持实时查询复杂度分析和策略推荐

### 🎯 动态策略选择
- **基础向量搜索**: 适用于简单的事实查询
- **标准检索+重排序**: 适用于中等复杂度的问题
- **增强检索+计算**: 结合化学计算工具的复杂查询
- **多轮检索**: 适用于需要多步推理的复杂问题
- **综合分析检索**: 最高级别的全面分析模式

### 📊 性能监控
- **实时统计**: 跟踪查询处理性能和策略使用情况
- **性能报告**: 提供详细的系统性能分析
- **优化建议**: 基于使用模式提供系统优化建议

## 启用方式

### 命令行启动
```bash
# 启用自适应检索功能
python main.py --enable-adaptive

# 同时启用自适应检索和双阶段检索
python main.py --enable-adaptive

# 禁用重排序器，仅使用自适应检索
python main.py --enable-adaptive --disable-reranker
```

### Web界面使用
1. 在功能类型中选择"自适应检索"
2. 或者在"自适应检索设置"中勾选"启用自适应检索"
3. 配置显示选项（复杂度分析、策略信息）

## 使用场景

### 简单查询示例
**问题**: "什么是氢气？"
- **复杂度**: LOW (0.2)
- **策略**: basic_vector_search
- **特点**: 快速响应，基础向量检索

### 中等复杂度查询
**问题**: "计算碳酸钙的摩尔质量并解释其在工业中的应用"
- **复杂度**: MEDIUM (0.6)
- **策略**: enhanced_retrieval_with_computation
- **特点**: 结合计算工具和知识检索

### 高复杂度查询
**问题**: "分析有机化学反应机理，包括中间体稳定性、反应动力学和热力学因素的综合影响"
- **复杂度**: VERY_HIGH (0.9)
- **策略**: comprehensive_analysis_retrieval
- **特点**: 多轮检索、深度分析、综合推理

- `analyze`: 分析查询复杂度
- `report`: 查看性能报告

## 技术原理

### 复杂度分析算法
```python
# 分析维度
- 语法复杂度: 句子长度、从句数量、专业术语密度
- 语义深度: 概念抽象程度、关系复杂性
- 计算需求: 数值计算、公式推导需求
- 推理要求: 多步推理、因果关系分析
```

### 策略映射规则
- **0.0-0.3**: 基础向量搜索
- **0.3-0.5**: 标准检索+重排序
- **0.5-0.7**: 增强检索+计算
- **0.7-0.8**: 多轮检索
- **0.8-1.0**: 综合分析检索

## 故障排除

### 常见问题

**Q: 自适应检索功能无法启用？**
A: 检查启动参数是否包含 `--enable-adaptive`，确保系统正确初始化。

**Q: 复杂度分析结果不准确？**
A: 复杂度分析基于多种启发式规则，可能需要根据具体领域进行调整。

**Q: 性能报告显示异常？**
A: 确保有足够的查询样本，新系统可能需要一定时间积累数据。
